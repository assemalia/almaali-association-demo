# لقطات الشاشة

ضع هنا لقطات شاشة للتطبيق ليجري عرضها في `README.md` الرئيسي.

الأسماء المتوقَّعة (استبدلها بلقطاتك بعد تشغيل التطبيق):

| الملف | الوصف المقترح |
|-------|----------------|
| `dashboard.png` | لوحة التحكم الرئيسية |
| `members.png` | صفحة الأعضاء |
| `attendance.png` | تسجيل الحضور |
| `subscriptions.png` | الاشتراكات والمدفوعات |

**كيفية الالتقاط:** شغّل النسخة التجريبية (`npm run dev` بعد `supabase start`) ثم التقط
الشاشات بدقة مناسبة (يُفضّل عرض 1280px+) واحفظها بهذه الأسماء في هذا المجلد.
